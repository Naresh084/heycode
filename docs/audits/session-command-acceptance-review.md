## Implemented from the review

The installed Claude 2.1.268 descriptor snapshot (local-only evidence: `tmp/terminal-evidence/session-command-acceptance-review-20260911T192700Z-e01574/source-metadata.json`) records the local binary path, hash and command descriptor offsets. It independently confirms `/branch [name]`, `/resume [conversation id or search term]`, and `/rename`'s `/name` alias. Descriptor inspection establishes grammar and discovery facts; it is not an execution or UI capture.

- `/branch [name...]` now names a copy of the current conversation. Existing UUID targeting is retained; `--session <id> [name...]` explicitly selects other saved IDs. The child title uses the shared durable rename owner and commits before the shell emits the switch outcome. A title-write failure reports the recoverable child ID and does not claim a completed switch. The original conversation remains unchanged.
- `/resume [session-or-search...]` now opens a focused, prefilled browser for text. Search stays bounded to 128 Unicode characters and the existing folder/visibility filters. It does not select a match automatically. UUIDs resume directly; `--session <id>` preserves explicit targeting of non-UUID saved IDs. Invalid/oversized/control-bearing search input is rejected without truncating it into a different query.
- `/name` now resolves through the central `/rename` descriptor, preserving its handler, dynamic availability and queued timing.
- Bare `/rewind` now opens a bounded picker of the latest 50 durable prompt boundaries. Enter selects a checkpoint, then a separate cancel-default choice offers conversation restoration or conversation plus confirmed native file edits. Mouse input only selects; Enter confirms. Paste and repeated Enter cannot confirm. Resize clears old mouse targets, and short frames keep the selected choice visible. The picker carries its origin session ID; the shell checks that ID when opening and confirming. The picker itself does not mutate a journal or file. Confirmation queues the ordinary `/rewind <turn> [files]` command, which retains the existing runtime idle/inbox/checkpoint/conflict checks.

Owned implementation is in `session_browser.rs`, `app/session_lifecycle.rs`, `rewind_picker.rs` and the bare-rewind branch of `session_control.rs`. The coordinator integrated the new request variants, modal input, rendering and accessibility in the shared shell and updated exact CLI synopsis expectations.
