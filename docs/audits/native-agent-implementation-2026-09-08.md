## Workflow interface and controls

The main transcript shows `workflow · <name>`. One rail below the composer shows the workflow name and successfully completed agents out of all declared Agent nodes, including queued nodes. Down focuses the rail; Enter opens phases and agents; Escape returns through agent detail to the unchanged draft. `/workflows` opens the workspace without model traffic. P pauses, R resumes and X stops using the actual owner service.

The final 19-capture native journey (local-only evidence: `docs/audits/assets/native-integration-2026-09-08/workflow-result.json`) ran three parallel child sessions through mixed progress, pause/resume, report writing, retained drafts, queued 0/3, Stop and switching runs. Durable coordinator job/outcome associations prevent late routine notices and raw IDs from leaking into live or replayed transcripts; failed and unknown attempts remain visible. Active dictation remains visible while the workflow workspace is open.

## Current native feature additions

The [dated feature matrix](../plans/provider-independent-parity.md) links the official source baseline and tracks L01–L20.

- [CodeMode](../plans/code-mode-implementation.md): real bounded async JavaScript, guarded tools, schema search, saved scripts, durable operation evidence and owner-scoped pause/resume/stop. Script writes/questions use the actual caller's checkpoint and inbox ownership.
- [Session features](../plans/session-controls.md): `/recap`, `/btw`, `/output-style`, asynchronous questions, skill diagnostics and conflict-aware native write/edit rewind. Conversation branches preserve the original session. Arbitrary shell/external-tool filesystem changes are not claimed as rewind checkpoints.
- [Native inspections](../plans/audit-custom-agents-implementation.md): `/review`, `/advisor` and `/security-review` use read-only native children and durable intent/result records. They inherit the selected native route or explicit preset override.
- [Fallback](../plans/model-fallback-implementation.md): one explicitly authorized target per session, independent provider activation, exact settings CAS, command-line pin preservation and at most one safe pre-output switch per user turn. Partial output, tool effects, opaque transitions and replay veto prevent fallback.
- [Remote hosts/routines](../plans/audit-remote-automation-implementation.md): removed by user request. Native terminal schedules, inbox, workflows and Plan remain; the linked remote report is historical only.
- [Interactive tools](../plans/audit-interactive-integrations-implementation.md): isolated browser DOM interaction, screenshots, artifact previews, notebook edits, native macOS controls and local speech. Explicit dependencies and the paused native GUI check are recorded below.
- [Workflow workspace](../plans/workflow-progress-backend.md): ordered phases, stable child identities before inference, durable agent summaries, actual successful-agent counts and measured timing. Interrupted work with an unknown end time has no invented duration. The interface keeps the transcript compact and exposes the full workspace through the progress rail and `/workflows`.
- [Human dictation](../plans/audit-voice-dictation-implementation.md): `/voice start`, `stop`, `cancel`, `status` and `insert` connect owned microphone capture to a configured local recognizer and the original composer. Draft edits are preserved, late results cannot enter a different session, and transcripts are never automatically submitted. Generated 16 kHz (local-only evidence: `docs/audits/assets/native-integration-2026-09-08/voice-generated-16khz.txt`) and 48 kHz (local-only evidence: `docs/audits/assets/native-integration-2026-09-08/voice-generated-48khz.txt`) speech passed through the actual recognizer into the composer; personal microphone recording remains paused.

## Provider and platform boundaries

Portable tools, planning, agents, workflows, monitoring and controls do not require a Claude/Codex subscription. Tests cover 22 production adapter routes through real Agent tool/result/continuation paths with synthetic transport/account fixtures. The five added cloud journeys cover Bedrock Converse, Mantle Responses/Messages and Vertex Gemini/Claude. They exposed and fixed Converse rejecting locally dispatched tools. No Bedrock InvokeModel adapter is implemented or claimed. These tests establish protocol correctness, not a paid account's entitlement or a live model's ability to choose the right tool.

Explicitly tool-incapable models cannot perform tool-driven work. Vision/audio/reasoning evidence stays model-specific; DOM and transcript text allow useful browser/speech workflows without claiming unsupported model modalities. Z.ai Coding Plan remains restricted by its official supported-client policy; general API credentials are not silently substituted. Cloud/custom fallback targets require independently configured connections where the product's factory contract requires them.

The full runtime checks were executed on macOS. Native computer capture/input requires the supported macOS version, Apple tools and OS permissions. Browser automation requires trusted Node/Playwright/Chromium paths. Local recognition requires an installed engine/model and an explicit command configuration. These dependencies are described in the interactive notes. No recognition-quality claim follows from a subprocess fixture; a separate actual generated-speech test is recorded there.

The [interactive follow-up](../plans/audit-interactive-integrations-qa-followup.md) verifies actual child/sibling browser isolation, private temporary directories, native filesystem scope and generated-speech recognition. This host's Chrome cannot nest its own sandbox inside macOS WorkspaceWrite Seatbelt, so that configuration returns an explicit error. The successful browser canaries used explicitly selected full-access process policy; there is no automatic permission relaxation. Normal close removes the owned browser directory; forced termination may retain temporary files after process settlement.
