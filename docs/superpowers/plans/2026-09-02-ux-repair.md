# heycode UX Repair Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make heycode usable the way a Claude Code / Codex CLI user expects: the conversation loop survives ordinary model output, slash commands run on one Enter with arguments, user-supplied config never bricks startup, project instructions reach the model, approvals are safe by default and never hang, the composer handles paste/newlines/history, config is predictable, headless is scriptable, and state is always visible.

**Architecture:** Every fix goes at the root cause named by the audit (`scratchpad/ux-results/UX_AUDIT_RAW.md`, 218 findings, 105/106 independently reproduced). Where two components must agree and nothing enforces it, the fix derives one from the other. TDD throughout: every task starts with a test that reproduces the audited behaviour and fails.

**Tech Stack:** Rust 1.97 / edition 2024, tokio, ratatui + tui-textarea, crossterm 0.28, serde. Workspace lints deny `unwrap`/`expect` outside `#[cfg(test)]` and `missing_docs`.

**Status: DONE (2026-09-02).** Tasks 1.1–1.6 landed; full gate 3843/0; black-box three-message TUI run green. Extra finding fixed on the way: empty `PermissionRequested.detail` for argument-free tools (R02 violation exposed by the self-validating hub). Codex `runtime_error` now keeps its own message. Restored: wait past the window, then assert absence.)

**Root cause.** `crates/heycode-agent/src/native_runtime.rs:549-557` maps every `assistant/message` with content to `RuntimeEventKind::FinalMessage`. The normalizer (`crates/heycode-runtime/src/normalization.rs:345-378`) treats `FinalMessage` as the turn's terminal phase: a later `ToolCall`/`CommentaryDelta` is `PhaseAfterFinal`, and `TurnFinished{Stop}` without a final is `MissingFinalMessage`. So text-then-tool-call (every real model, every tool call) and empty replies both raise `Protocol`. The app-server's session-lifetime stream (`crates/heycode-app-server/src/lib.rs:1050-1063`, `TurnEvents`) is then permanently errored, so every later turn fails instantly. The TUI shows `app-server is unavailable` and can stay `Thinking…`.

- Produces: `pub(crate) struct NativeEventTranslator { pending_final: Option<String>, step_streamed: bool }` with `pub(crate) fn translate(&mut self, event: &SessionEvent) -> Vec<RuntimeEventKind>`.

Rules the translator enforces (these are the R02 contract in `normalization.rs`):
1. `turn/start` → reset state, emit `TurnStarted`.
2. `step/start` → `step_streamed = false`.
3. `assistant/chunk{text}` → `CommentaryDelta`; `step_streamed = true`. `reasoning` → `ReasoningDelta`.
4. `assistant/message{content, usage}` → hold `content` in `pending_final` (do not emit); emit `Usage` if present.
5. `tool/call` → if a pending final exists and the step was **not** streamed, emit it as `CommentaryDelta` so SDK clients still see the text; clear `pending_final`; emit `ToolCall`.
6. `turn/end{reason}` → if a pending final exists and the step was not streamed, emit `CommentaryDelta{text}` first; then emit `FinalMessage{text: pending_final.take().unwrap_or_default()}` when `reason == Stop` **or** a pending final exists (empty text is legal — `validate_output_text(.., allow_empty=true)`); then `TurnFinished`.
7. Everything else unchanged from today's arms.

```rust
/// Translates committed session events into the R02 runtime vocabulary.
///
/// Intermediate assistant text is commentary and the one final message closes
/// the turn, so a step that speaks and then calls a tool — the normal shape of
/// every real turn — yields `CommentaryDelta`, `ToolCall`, … and exactly one
/// `FinalMessage` immediately before `TurnFinished`. An empty stop reply still
/// carries an (empty) final message, which the normalizer permits.
#[derive(Default)]
pub(crate) struct NativeEventTranslator {
    /// Text of the latest assistant message, held until the turn shows whether
    /// it was the last step or a preface to a tool call.
    pending_final: Option<String>,
    /// Whether the current step already streamed its text as chunks, so the
    /// held message must not be replayed as a delta.
    step_streamed: bool,
}

impl NativeEventTranslator {
    pub(crate) fn translate(&mut self, event: &SessionEvent) -> Vec<RuntimeEventKind> {
        match &event.kind {
            SessionEventKind::TurnStart { turn } => {
                self.pending_final = None;
                self.step_streamed = false;
                vec![RuntimeEventKind::TurnStarted { turn: RuntimeTurnId::from_native_turn(*turn) }]
            }
            SessionEventKind::StepStart { .. } => {
                self.step_streamed = false;
                Vec::new()
            }
            SessionEventKind::AssistantChunk { text, reasoning, .. } => {
                let mut events = Vec::new();
                if let Some(text) = text {
                    self.step_streamed = true;
                    events.push(RuntimeEventKind::CommentaryDelta { text: text.clone() });
                }
                if let Some(text) = reasoning {
                    events.push(RuntimeEventKind::ReasoningDelta { text: text.clone() });
                }
                events
            }
            SessionEventKind::AssistantMessage { content, usage, .. } => {
                if !content.is_empty() {
                    self.pending_final = Some(content.clone());
                }
                usage.map(|usage| RuntimeEventKind::Usage { usage }).into_iter().collect()
            }
            SessionEventKind::ToolCall { call_id, name, args, .. } => {
                let mut events = self.flush_unstreamed_text();
                events.push(RuntimeEventKind::ToolCall {
                    call_id: call_id.clone(),
                    name: name.clone(),
                    arguments: args.clone(),
                });
                events
            }
            SessionEventKind::TurnEnd { turn, reason } => {
                let mut events = self.flush_unstreamed_text_keeping_final();
                let final_text = self.pending_final.take();
                let reason = finish_reason(reason);
                if reason == RuntimeFinishReason::Stop || final_text.is_some() {
                    events.push(RuntimeEventKind::FinalMessage { text: final_text.unwrap_or_default() });
                }
                events.push(RuntimeEventKind::TurnFinished {
                    turn: RuntimeTurnId::from_native_turn(*turn),
                    reason,
                });
                events
            }
            // … every remaining arm exactly as it is today (ToolResult, RichToolResult,
            // CompactionApplied, PlanMode, …) …
        }
    }

    /// A held message that was never streamed becomes commentary and is dropped.
    fn flush_unstreamed_text(&mut self) -> Vec<RuntimeEventKind> {
        match self.pending_final.take() {
            Some(text) if !self.step_streamed => vec![RuntimeEventKind::CommentaryDelta { text }],
            _ => Vec::new(),
        }
    }

    /// Like `flush_unstreamed_text` but keeps the message for the final.
    fn flush_unstreamed_text_keeping_final(&mut self) -> Vec<RuntimeEventKind> {
        match &self.pending_final {
            Some(text) if !self.step_streamed => vec![RuntimeEventKind::CommentaryDelta { text: text.clone() }],
            _ => Vec::new(),
        }
    }
}
```

```rust
fn run_or_complete_palette_command(&mut self) {
    let text = self.input.lines().join("\n");
    let Some((typed_id, typed_args)) = parse_slash(&text) else { return self.submit_composer(); };
    let highlighted = self.command_palette.as_ref().and_then(|p| p.matches.get(p.selected)).filter(|row| row.preselectable || p_user_navigated(self));
    match highlighted {
        // Exact id typed, or arguments typed: run what the user wrote.
        _ if self.command_exists(&typed_id) || !typed_args.is_empty() => { self.command_palette = None; self.submit_composer(); }
        Some(row) if row.entry.descriptor.arguments().is_empty() => {
            // Prefix of a no-argument command: complete and run in one Enter.
            self.replace_input(format!("/{}", row.entry.descriptor.id()));
            self.command_palette = None; self.submit_composer();
        }
        Some(row) => {
            // Prefix of an argument-taking command: complete, let the user add arguments.
            self.replace_input(format!("/{} ", row.entry.descriptor.id()));
            self.command_palette = None;
        }
        None => { self.command_palette = None; self.submit_composer(); } // submit_composer reports "unknown command"
    }
}
```
