# Security

Please report potential vulnerabilities privately through the repository's **Security → Report a vulnerability** page. Do not post credentials, exploit-ready details involving other users, or private conversations in public issues.

Include the affected HeyCode version, operating system, a minimal reproduction using synthetic data, and the impact you observed. We will investigate reports against the latest release; no response-time commitment or bounty is currently offered.

HeyCode can read files and run tools within the permissions you grant. Treat project instructions, tool output, plugins, and MCP servers as untrusted inputs. Provider credentials and local history belong in the private HeyCode home, never in this repository.

A clean secret-scan result is not a guarantee that no secret exists. Publication checks combine automated scanning with review of intentional assets. Public releases start from a curated source snapshot rather than importing private development artifacts and history.
